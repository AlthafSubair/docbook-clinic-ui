# docbook-clinic-ui

Clinic administration portal for DocBook, built with React 19, Vite, Tailwind CSS v4, and React Router v8.

## Getting Started

```bash
pnpm install
pnpm dev
```

## Features
- **Clinic Auth Portal**: Login flow supporting username/email and password with validation.
- **Shared UI Component System**: Integrated with `docbook-ui-package`.
- **Responsive Layout**: Tailored for mobile, tablet, and desktop viewports.
